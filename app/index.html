Open OpenTimestamps.org verifier ↗

For new ProofStamps, use the original file together with the downloaded .ots proof on OpenTimestamps.org. Legacy Manifest-v1 receipts use the prefilled verifier link instead.

Browser verification is a convenience check. It verifies the OpenTimestamps Bitcoin attestation against a raw block header fetched through Blockstream. It is not equivalent to independently validating Bitcoin consensus with your own Bitcoin Core node.

ProofStamp confirms exact file bytes and timestamp evidence. It does not prove authorship or whether the contents are true.

How it works

File → SHA-256 → OpenTimestamps → Bitcoin.

01

Hash locally

Your browser calculates the file's SHA-256 fingerprint. The file is not uploaded.

02

Timestamp the fingerprint

OpenTimestamps timestamps that exact SHA-256 and later anchors it to Bitcoin.

03

Verify anywhere

Use ProofStamp with the file + receipt, or use the original file + .ots proof with OpenTimestamps.

What a ProofStamp does not prove

It does not prove who created a file, whether its contents are true, or when the file was originally created.

Independent verification

New ProofStamps timestamp the file SHA-256 directly. Download the .ots proof and verify it with the original file using OpenTimestamps.org, the OpenTimestamps CLI, or your own Bitcoin Core node.

Older Manifest-v1 ProofStamp receipts remain supported by this app, but their .ots proof timestamps the legacy Manifest commitment rather than the raw file hash.
