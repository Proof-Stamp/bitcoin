The OpenTimestamps link opens the official verifier with this proof and its Manifest commitment prefilled. Your source file is not sent.

          
Browser verification is a convenience check. It verifies the OpenTimestamps Bitcoin attestation against a raw block header fetched through Blockstream. It is not equivalent to independently validating Bitcoin consensus with your own Bitcoin Core node.

        


        

          What this verifies
          
ProofStamp can verify that these exact file bytes match the timestamped record. It does not prove who created the file, whether its contents are true, or when the file was originally created.

        What a ProofStamp does not prove
        
It does not prove who created a file, whether its contents are true, or when the file was originally created.

      


      

        Independent verification
        
A completed proof can also be checked with standard OpenTimestamps tooling and your own Bitcoin Core node. The proof does not depend on ProofStamp staying online.

        
Using OpenTimestamps.org manually: a ProofStamp .ots file timestamps the Manifest commitment, not the original source-file hash. Pairing the .ots file with the original source file on OpenTimestamps.org will therefore show a mismatch. Use the prefilled “Verify this proof on OpenTimestamps.org” link shown with the proof, or use the independent verification instructions below.
